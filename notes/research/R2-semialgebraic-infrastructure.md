## 1. Scope — statements covered, in math and as Lean-style signatures

Conventions. Points of ℝⁿ are `ι → ℝ` for a finite index type `ι` (specialise `ι := Fin n`);
ℝⁿ × ℝᵐ is `ι ⊕ κ → ℝ` with `Sum.elim`; ℝⁿ × ℝ is `ι ⊕ Unit → ℝ` (the "value coordinate" is
`Sum.inr ()`). Polynomials: `MvPolynomial ι ℝ`, `MvPolynomial.eval x p`. The sup-norm topology on
`ι → ℝ` is the Pi topology (so `IsClosed`, `closure`, `interior` are Mathlib's).

### S1. Semialgebraic sets (Def 2.1 + Appendix C)

```lean
/-- Primary definition (B″): the Boolean algebra of sets generated by zero sets and positivity sets.
    Identical, symbol for symbol, to `TauCeti.IsSemialgebraic`. -/
def IsSemialgebraic {ι : Type*} (s : Set (ι → ℝ)) : Prop :=
  s ∈ generateSetAlgebra
    (Set.range (fun p : MvPolynomial ι ℝ => {x | MvPolynomial.eval x p = 0}) ∪
     Set.range (fun p : MvPolynomial ι ℝ => {x | 0 < MvPolynomial.eval x p}))

/-- Paper's basic set (A): one equation, finitely many strict inequalities. -/
def IsBasicSemialgebraic (s : Set (ι → ℝ)) : Prop :=
  ∃ (P : MvPolynomial ι ℝ) (k : ℕ) (Q : Fin k → MvPolynomial ι ℝ),
    s = {x | eval x P = 0 ∧ ∀ j, 0 < eval x (Q j)}

theorem isSemialgebraic_iff_finite_union_basic (s : Set (ι → ℝ)) :
    IsSemialgebraic s ↔ ∃ (m : ℕ) (S : Fin m → Set (ι → ℝ)),
      (∀ i, IsBasicSemialgebraic (S i)) ∧ s = ⋃ i, S i                      -- (A) ⇔ (B)

theorem IsSemialgebraic.exists_disjoint_basic (hs : IsSemialgebraic s) :            -- Prop C.1
    ∃ (m : ℕ) (S : Fin m → Set (ι → ℝ)), (∀ i, IsBasicSemialgebraic (S i)) ∧
      Pairwise (fun i j => Disjoint (S i) (S j)) ∧ s = ⋃ i, S i

/-- Sign-condition normal form (the workhorse; TauCeti: `exists_eq_setOf_sign_eval`). -/
theorem IsSemialgebraic.exists_eq_setOf_sign_eval (hs : IsSemialgebraic s) :
    ∃ (m : ℕ) (p : Fin m → MvPolynomial ι ℝ) (Φ : (Fin m → SignType) → Prop),
      s = {x | Φ fun i => SignType.sign (eval x (p i))}
```

### S2. Semialgebraic functions, real- and extended-real-valued (Def 2.1, Def 2.2)

```lean
def graphSet (f : (ι → ℝ) → ℝ) : Set (ι ⊕ Unit → ℝ) :=
  {z | f (z ∘ Sum.inl) = z (Sum.inr ())}

def IsSemialgebraicMap (f : (ι → ℝ) → ℝ) : Prop := IsSemialgebraic (graphSet f)

/-- Def 2.2. `dom` is derivable (complement of `top ∪ bot`), so it is not a field. -/
structure IsSemialgebraicEReal (f : (ι → ℝ) → EReal) : Prop where
  top   : IsSemialgebraic {x | f x = ⊤}
  bot   : IsSemialgebraic {x | f x = ⊥}
  graph : IsSemialgebraic {z : ι ⊕ Unit → ℝ | f (z ∘ Sum.inl) = ((z (Sum.inr ()) : ℝ) : EReal)}

theorem IsSemialgebraicEReal.dom (hf : IsSemialgebraicEReal f) :
    IsSemialgebraic {x | ∃ r : ℝ, f x = r}

/-- "graph ⊆ ℝⁿ × EReal is semialgebraic in a suitable sense": encode EReal as ℝ × {−1,0,1}. -/
def extGraph (f : (ι → ℝ) → EReal) : Set (ι ⊕ Fin 2 → ℝ) :=
  {z | (z (Sum.inr 1) = 0 ∧ f (z ∘ Sum.inl) = ((z (Sum.inr 0) : ℝ) : EReal)) ∨
       (z (Sum.inr 1) = 1 ∧ z (Sum.inr 0) = 0 ∧ f (z ∘ Sum.inl) = ⊤) ∨
       (z (Sum.inr 1) = -1 ∧ z (Sum.inr 0) = 0 ∧ f (z ∘ Sum.inl) = ⊥)}

theorem isSemialgebraicEReal_iff_extGraph : IsSemialgebraicEReal f ↔ IsSemialgebraic (extGraph f)
theorem isSemialgebraicEReal_coe_iff (f : (ι → ℝ) → ℝ) :
    IsSemialgebraicEReal (fun x => (f x : EReal)) ↔ IsSemialgebraicMap f
```

### S4. Finiteness theorem (Prop 2.4) — assumed, quarantined

```lean
class HasFinitenessTheorem : Prop where
  exists_eq_iUnion_iInter_nonneg {n : ℕ} {s : Set (Fin n → ℝ)} :
    IsSemialgebraic s → IsClosed s →
```

### S5. Growth (Prop 2.5, CORRECTED — see §3 item 1)

Math: let f : ℝⁿ → ℝ have semialgebraic graph and be bounded on bounded sets. Then there are
c ∈ ℝ and M ∈ ℕ with |f(x)| ≤ c (1 + Σᵢ xᵢ²)^M for all x.
```lean
theorem IsSemialgebraicMap.exists_poly_bound [HasSemialgebraicProjections]
    {f : (Fin n → ℝ) → ℝ} (hf : IsSemialgebraicMap f)
    (hb : ∀ r : ℝ, ∃ B : ℝ, ∀ x, (∑ i, x i ^ 2) ≤ r → |f x| ≤ B) :
    ∃ (c : ℝ) (M : ℕ), ∀ x, |f x| ≤ c * (1 + ∑ i, x i ^ 2) ^ M
```
(The paper's form `|f(x)| ≤ ‖x‖^N for ‖x‖ ≥ C` follows: for Σxᵢ² ≥ 1, c(1+Σxᵢ²)^M ≤ 2^M c (Σxᵢ²)^M
≤ ‖x‖₂^{2M+2} once ‖x‖₂² ≥ 2^M c.)

### S6. Value functions are extended-real semialgebraic (Prop 2.6, CORRECTED — see §3 items 2–3)

Data: `P Q : MvPolynomial (Fin n ⊕ Fin m) ℝ`, `Y : Set (Fin m → ℝ)` semialgebraic (boxes included).
`Θ x := {y ∈ Y | ∀ y' ∈ Y, Q(x,y) ≤ Q(x,y')}`, `φ x := ⨅ y ∈ Θ x, ((P(x,y) : ℝ) : EReal)`.
```lean
theorem valueFun_isSemialgebraicEReal [HasSemialgebraicProjections]
    (hY : IsSemialgebraic Y) : IsSemialgebraicEReal (valueFun P Q Y)
```
with the first-order descriptions (all of which are theorems about `⨅`, §2.F):
- dom⁺ = {x | ∀ y, y ∉ Θ(x)};
- dom⁻ = {x | ∀ δ : ℝ, ∃ y ∈ Θ(x), P(x,y) < δ}  (= "Θ(x) ≠ ∅ and P unbounded below on it");
- dom  = {x | ∃ δ : ℝ, (∀ y ∈ Θ(x), δ ≤ P(x,y)) ∧ ∀ ε > 0, ∃ y ∈ Θ(x), P(x,y) < δ + ε};
- graph(φ|dom) = {(x,t) | (∀ y ∈ Θ(x), t ≤ P(x,y)) ∧ ∀ ε > 0, ∃ y ∈ Θ(x), P(x,y) < t + ε}
  (the paper's `{(x,P(x,y)) | y ∈ Θ(x), ∀ y' ∈ Θ(x), P(x,y) ≤ P(x,y')}` is wrong without attainment).
Pessimistic version: replace ⨅ by ⨆, `<` by `>` throughout.

## 2. Proof route — DAG of lemmas with implementer-level sketches

Notation: `gen` := the generating family `range {p=0} ∪ range {0<p}`.

### 2.A Boolean/algebraic layer (no T–S)

**L1 (generators).** `isSemialgebraic_eval_eq_zero p`, `isSemialgebraic_eval_pos p` — by
`self_subset_generateSetAlgebra` (`Mathlib/MeasureTheory/SetAlgebra.lean:128`) and `Set.mem_range_self`.

**L2 (Boolean closure).** `empty, univ, compl, union, inter, sdiff, biUnion (Finset), biInter, iUnion/iInter
([Fintype])` — all from `isSetAlgebra_generateSetAlgebra` (`SetAlgebra.lean:121`) and the `IsSetAlgebra`
API (`univ_mem :68`, `inter_mem :72`, `sdiff_mem :78`, `biUnion_mem :90`, `biInter_mem :94`;
`compl_mem/union_mem/empty_mem` are the structure fields, `:60`).

**L3 (derived sign sets).** `{p ≠ 0} = {0 < p²}` (L1 with `p^2`; `eval` is a ring hom, `map_pow`);
`{p ≥ 0} = {0 < p} ∪ {p = 0}`; `{p < 0} = {0 < -p}`; `{p ≤ 0} = {p<0} ∪ {p=0}`; `{p < q} = {0 < q - p}`;
`{p = q}`; `{sign p = σ}` by cases on `σ : SignType` (`SignType.sign_apply`, `Mathlib/Basic/Sign/Defs.lean:273`,
`sign_pos :280`, `sign_neg :283`, `sign_eq_zero_iff :311`).

**L4 (preimage under polynomial maps).** For `F : κ → MvPolynomial ι ℝ` and `S : Set (κ → ℝ)` semialgebraic,
`(fun x i => eval x (F i)) ⁻¹' S` is semialgebraic. Proof: `generateSetAlgebra_induction`
(`SetAlgebra.lean:134`) on `S`; base case `{y | eval y p = 0}`: its preimage is `{x | eval x (bind₁ F p) = 0}`
using `MvPolynomial.eval₂Hom_bind₁` (`Mathlib/Algebra/MvPolynomial/Monad.lean:250`) / `aeval_bind₁` (`:254`)
(`eval x = eval₂Hom (RingHom.id ℝ) x`); positivity case identical; `compl`/`union` cases: `preimage_compl`,
`preimage_union`. Corollaries (all instances of L4 with explicit `F`):
- **reindexing** `IsSemialgebraic S → IsSemialgebraic ((· ∘ e) ⁻¹' S)` for any `e : ι → κ` (F i := X (e i));
  for `e : ι ≃ κ` also the image form (`image_eq_preimage_of_inverse`);
- **products / cylinders**: `{z : ι ⊕ κ → ℝ | z ∘ Sum.inl ∈ S}` (F := X ∘ Sum.inl) and
  `{z | z ∘ inl ∈ S ∧ z ∘ inr ∈ T}` (intersection);
- **graphs of polynomial maps**: `{z : ι ⊕ κ → ℝ | ∀ j, z (inr j) = eval (z ∘ inl) (G j)}`
  `= ⋂ j {z | eval z (X (inr j) - rename inl (G j)) = 0}` (`MvPolynomial.eval_rename`,
  `Mathlib/Algebra/MvPolynomial/Rename.lean:244`); so polynomial maps are `IsSemialgebraicMap`;
- **boxes**: `Set.pi univ (fun i => Icc (a i) (b i))` (and `Ici`, `Iic`, `univ`) = finite intersections of
  L3 sets; EReal-endpoint boxes: per coordinate, case on the endpoint (`⊥`/`⊤`/real);
- **finite sets, singletons**: `{x} = ⋂ i {x | eval x (X i - C (x i)) = 0}`;
- **sup-norm balls** `{x | ∀ i, |x i - c i| < r}`.

**L5 (sign-condition normal form, S1 last theorem).** Induction with `generateSetAlgebra_induction`,
motive `∃ m p Φ, s = {x | Φ (fun i => sign (eval x (p i)))}`:
- base `{p=0}`: m=1, p := ![p], Φ σ := σ 0 = 0; base `{0<p}`: Φ σ := σ 0 = 1 (L3);
- empty: m=0, Φ := fun _ => False; compl: same (m,p), Φ' := ¬Φ;
- union of (m₁,p₁,Φ₁),(m₂,p₂,Φ₂): m := m₁+m₂, p := Fin.append p₁ p₂ (or via `finSumFinEquiv`,
  `Mathlib/Logic/Equiv/Fin/Basic.lean:224`), Φ σ := Φ₁ (σ ∘ castAdd) ∨ Φ₂ (σ ∘ natAdd).
Conversely every `{x | Φ (sign ∘ p)}` is semialgebraic: it equals `⋃ σ ∈ {σ | Φ σ}, ⋂ i, {sign (p i) = σ i}`
(`SignType` is a `Fintype`, `Basic/Sign/Defs.lean:32`; so is `Fin m → SignType`), use L2+L3.

**L6 (cells).** For `p : Fin m → MvPolynomial ι ℝ` and `σ : Fin m → SignType`, the *cell*
`C σ := {x | ∀ i, sign (eval x (p i)) = σ i}` is basic in the paper's sense:
`C σ = {x | eval x (∑ i ∈ univ.filter (σ · = 0), (p i)^2) = 0 ∧ ∀ i ∈ filter (σ · = 1), 0 < eval x (p i)
∧ ∀ i ∈ filter (σ · = -1), 0 < eval x (-(p i))}` — the sum of squares vanishes iff each summand does
(`Finset.sum_eq_zero_iff_of_nonneg`, used e.g. at `Mathlib/Algebra/Order/BigOperators/Ring/Finset.lean:89`,
with `sq_nonneg`, `pow_eq_zero_iff`); repackage the two `filter`s as one `Fin k → MvPolynomial` via
`Finset.equivFin`/`orderEmbOfFin`. Cells for distinct σ are disjoint (a point has one sign vector),
and `⋃ σ, C σ = univ`.

**L7 ((A) ⇒ (B)).** A basic set is `{P=0} ∩ ⋂ j {0 < Q j}` (L1, L2); a finite union of them is in the
algebra (L2). Trivial.

**L8 ((B) ⇒ (A) and Prop C.1, reconstructed).** Given `hs`, take (m,p,Φ) from L5. Then
`s = ⋃ σ ∈ (univ.filter Φ), C σ` and the `C σ` are pairwise disjoint basic sets (L6). Enumerate the
filtered finset as `Fin m'` (`Finset.equivFin`). This proves both `isSemialgebraic_iff_finite_union_basic`
and `exists_disjoint_basic`. This is exactly the paper's Appendix C argument once repaired (§3 item 4):
the family H of all polynomials, 3^{|H|} sign vectors, each cell either inside or disjoint from each Sᵢ;
the two points the paper glosses over are (i) `{h < 0}` must be written `{0 < −h}` and (ii) a cell may
carry several equations, merged by a sum of squares.

Alternative for L8 only: `mem_generateSetAlgebra_elim` (`SetAlgebra.lean:196`) gives the DNF
"finite union of finite intersections of generators or complements of generators" directly; then
expand complements by L3 and distribute. More bookkeeping (nested `Set.Finite`), same effort; L5 is
preferred because it also yields disjointness and the thin-set lemma (L12) for free.

### 2.B Projection layer (T–S assumed through `HasSemialgebraicProjections`)

**L9 (one coordinate, any position, any finite index type).** From the field (coordinate `0` of
`Fin (n+1)`): for `S : Set (ι → ℝ)` with `ι` finite and `i₀ : ι`, `{v : {i // i ≠ i₀} → ℝ | ∃ t, S ∋ (extend v t)}`
is semialgebraic. Proof: choose `e : ι ≃ Fin (n+1)` with `e i₀ = 0` (`Fintype.equivFin` composed with a
transposition `Equiv.swap`), transport `S` by L4 (`image_comp_equiv`), apply the field, transport back.

**L10 (`exists_sumElim`, S3).** Induction on `Fintype.card β` (or on a `List` enumeration of β): project one
coordinate of `β` at a time with L9, reindexing `α ⊕ β` as `(α ⊕ β') ⊕ Unit`. Base β empty:
`{v | ∃ u : β → ℝ, Sum.elim v u ∈ S}` is the preimage of `S` under `v ↦ Sum.elim v (isEmptyElim)`, L4.
**L11 (`forall_sumElim`).** `{v | ∀ u, …} = {v | ∃ u, Sum.elim v u ∈ Sᶜ}ᶜ`, L2 + L10.
Bounded quantifiers: `∀ ε > 0, φ` is `∀ ε, ε ≤ 0 ∨ φ`; `∃ y ∈ Θ(x), φ` is `∃ y, y ∈ Θ(x) ∧ φ`; each layer is
"Boolean combination (L2–L4) of semialgebraic sets in the enlarged space, then L10/L11". The
reindexings `(α ⊕ β) ⊕ γ ≃ α ⊕ (β ⊕ γ)` etc. are `Equiv.sumAssoc` + L4. (Pitfall §5.)

**L_closure (S7).** With sup metric: `y ∈ closure s ↔ ∀ ε > 0, ∃ x ∈ s, dist y x < ε`
(`Metric.mem_closure_iff`, `Mathlib/Topology/MetricSpace/Pseudo/Defs.lean:1231`), and
`dist y x < ε ↔ ∀ i, dist (y i) (x i) < ε` (`dist_pi_lt_iff`, `Topology/MetricSpace/Pseudo/Pi.lean:70`,
needs `0 < ε`), `Real.dist_eq` → `|y i - x i| < ε ↔ -ε < y i - x i ∧ y i - x i < ε` (L3 in the variables
`(y, ε, x) : ι ⊕ Unit ⊕ ι`). Then
`closure s = {y | ∀ ε, ε ≤ 0 ∨ ∃ x, x ∈ s ∧ ∀ i, …}` = L11 ∘ (L2 ∘ L10). Interior: `interior s = (closure sᶜ)ᶜ`
(`interior_compl`/`closure_compl`). (TauCeti proves `IsSemialgebraic.closure` exactly this way.)

### 2.C The thin-set lemma and univariate bounds (for Prop 2.5; shared with Łojasiewicz)

**L12 (thin set ⇒ algebraic, with positive degree in the isolated variable).** Let `S : Set (Fin (n+1) → ℝ)`
be semialgebraic and suppose no fibre `{t | Fin.cons t x ∈ S}` contains an open interval (e.g. all fibres
are subsingletons — partial graphs). Then there is `P ≠ 0` with `MvPolynomial.degreeOf 0 P > 0` and
`S ⊆ {P = 0}`.
Proof. L5: `S = {z | Φ (sign ∘ p)}`. For σ with `Φ σ` and `C σ ≠ ∅` pick `z = Fin.cons t x ∈ C σ`. Let
`E σ := {i | σ i = 0 ∧ 0 < degreeOf 0 (p i)}`. Claim `E σ ≠ ∅`. Otherwise: for `i` with `σ i = 0`,
`degreeOf 0 (p i) = 0`, so `finSuccEquiv ℝ n (p i)` has `natDegree = 0` (`natDegree_finSuccEquiv`,
`Mathlib/Algebra/MvPolynomial/Equiv.lean:772`), hence is a constant `C c` (`Polynomial.eq_C_of_natDegree_eq_zero`,
`Algebra/Polynomial/Degree/Operations.lean:485`), hence `eval (Fin.cons t' x) (p i) = eval (Fin.cons t x) (p i) = 0`
for every `t'` (`eval_eq_eval_mv_eval'`, `Equiv.lean:669`). For `i` with `σ i ≠ 0`, `t' ↦ eval (Fin.cons t' x) (p i)`
is continuous (`MvPolynomial.continuous_eval`, `Topology/Algebra/MvPolynomial.lean:31`, composed with the
continuity of `t' ↦ Fin.cons t' x` — `continuous_pi` + `Fin.cases`; locate the exact lemma, e.g.
`Continuous.fin_cons`/`continuous_pi_iff`), and nonzero at `t`, so by `ContinuousAt.eventually_lt`
(`Topology/Order/OrderClosed.lean:702`) it keeps its sign on a neighbourhood of `t`; intersecting finitely
many neighbourhoods gives an open interval `J ∋ t` with `Fin.cons t' x ∈ C σ ⊆ S` for `t' ∈ J` — contradiction.
Choose `i σ ∈ E σ`; set `P := ∏ σ ∈ univ.filter (fun σ => Φ σ ∧ (C σ).Nonempty), p (i σ)` (if the filter is
empty, `S = ∅`, take `P := X 0`). `P ≠ 0` as a product of nonzero factors (`Finset.prod_ne_zero_iff`);
`S ⊆ {P = 0}` since every point of `S` is in some such cell and `eval_prod` (`Algebra/MvPolynomial/Eval.lean:299`)
has a zero factor (`Finset.prod_eq_zero_iff`, `Algebra/BigOperators/GroupWithZero/Finset.lean:57`);
`degreeOf 0 P > 0`: apply the ring hom `finSuccEquiv` (`map_prod`), then `Polynomial.natDegree_prod`
(`Algebra/Polynomial/BigOperators.lean:367`, needs each factor `≠ 0`, ℝ-coefficient ring `MvPolynomial (Fin n) ℝ`
is a domain) gives `natDegree = ∑ natDegree (…) ≥ natDegree (first factor) > 0`.
This is Schweighofer's "deg_Y fᵢ > 0, otherwise {x} × (c,d) ⊆ Γ_h" step (6.2.1), made uniform.

**L13 (univariate root bound — NOT IN MATHLIB; 5 lines).** For `a : Fin (d+1) → ℝ` with `a d ≠ 0` and
`∑ k, a k * s^k = 0`: `|s| ≤ max 1 ((∑ k < d, |a k|) / |a d|)`. Proof: if `|s| ≥ 1` then

**L14 (univariate polynomial asymptotics — in Mathlib).** For `q : ℝ[X]`, `q ≠ 0`: eventually `q.eval ρ ≠ 0`
(`Polynomial.eventually_atTop_not_isRoot`, `Mathlib/Analysis/Polynomial/Basic.lean:40`), and a uniform

(`Algebra/Polynomial/Eval/Degree.lean:63`) and `ρ^k ≤ (1+ρ)^natDegree`.

**L15 (one-variable growth = Schweighofer 6.2.1).** Let `G : Set (Fin 2 → ℝ)` be semialgebraic with every
fibre `{s | ![s, ρ] ∈ G}` a subsingleton (coordinate 0 = value `s`, coordinate 1 = argument `ρ`; this
matches `finSuccEquiv` isolating variable 0). Then `∃ c M ρ₀, ∀ ρ ≥ ρ₀, ∀ s, ![s,ρ] ∈ G → |s| ≤ c (1+ρ)^M`.
Proof: L12 gives `P` with `degreeOf 0 P = d > 0`, `G ⊆ {P=0}`. Let `P' := finSuccEquiv ℝ 1 P : (MvPolynomial (Fin 1) ℝ)[X]`,
`a k := P'.coeff k` (`natDegree P' = d`, `a d ≠ 0`); identify `MvPolynomial (Fin 1) ℝ ≅ ℝ[X]`
(`finSuccEquiv ℝ 0` then `isEmptyAlgEquiv`, `Equiv.lean:606, :222`) to get univariate `a k`. For `![s,ρ] ∈ G`:
`0 = eval (Fin.cons s ![ρ]) P = Polynomial.eval s (P'.map (eval ![ρ]))` (`eval_eq_eval_mv_eval'`), i.e.
`∑ k ≤ d, (a k).eval ρ * s^k = 0`. For ρ ≥ ρ₀ (L14 applied to `a d`): `|(a d).eval ρ| ≥ c₀ > 0`; L13 + L14
upper bounds give `|s| ≤ max 1 (∑_{k<d} C_k (1+ρ)^{m_k} / c₀) ≤ c (1+ρ)^M`.

### 2.D Growth of locally bounded semialgebraic functions (Prop 2.5, corrected) and what Thm 2.15/2.20 need

**L16 (S5).** Define `g ρ := sSup ((fun x => |f x|) '' {x | ∑ i, x i^2 ≤ ρ})` for `ρ ≥ 0`. By `hb` the image
is bounded above and nonempty (`x = 0`), so `csSup` behaves (`le_csSup`
`Mathlib/Order/ConditionallyCompleteLattice/Basic.lean:101`, `csSup_le :105`, `lt_csSup_iff :270`).
First-order description of `G := {(s,ρ) | ρ ≥ 0 ∧ s = g ρ}`:
`s = g ρ ↔ (∀ x, ∑ x i^2 ≤ ρ → |f x| ≤ s) ∧ ∀ ε > 0, ∃ x, ∑ x i^2 ≤ ρ ∧ s - ε < |f x|`, where `|f x| ≤ s` is
`∃ t, (t = f x) ∧ -s ≤ t ∧ t ≤ s` with `t = f x` expressed through `graphSet f` (L4 preimage), and `|f x| > s-ε`
similarly. So `G` is semialgebraic by L2–L4, L10, L11 (three quantifier layers, 2 of them universal).
Fibres of `G` over ρ are subsingletons ⇒ L15 ⇒ `g ρ ≤ c₁ (1+ρ)^M` for `ρ ≥ ρ₀`. For any `x` with
`ρ := ∑ x i^2 ≥ ρ₀`: `|f x| ≤ g ρ` (`le_csSup`) `≤ c₁(1+ρ)^M`. For `ρ ≤ ρ₀`: `|f x| ≤ B(ρ₀) ≤ B(ρ₀)(1+ρ)^M`.
Take `c := max c₁ (B ρ₀)`.

**Where Prop 2.5 is used, and what is really needed.**
- Thm 2.15, observation 3: `f ∈ SA ∩ LSC ∩ CB`; CB = bounded on compact sets = `hb` (closed balls of
  the sup norm are compact: `isCompact_univ_pi` `Topology/Compactness/Compact.lean:1172` with
  `isCompact_Icc`). So the corrected L16 is exactly what is used. The two-sided bound `|f| ≤ c(1+Σx²)^M`
  is *necessary* for the theorem as stated: if `f ∈ P_bounded` then `|f(x)| ≤ max_{y∈Y}|P(x,y)|`, a
  polynomial bound. Hence Prop 2.5 cannot be dropped from the theorem; but it can be *layered*:
  state `Thm 2.15'` with the extra hypothesis `∃ c M, ∀ x, |f x| ≤ c(1+Σx²)^M` (no T–S needed for that part
  beyond what the construction already uses), and derive Thm 2.15 from Thm 2.15' + L16. Recommended.
- Thm 2.20, observation 2: applied to polynomials `Pᵢ`. No semialgebraic geometry needed:
  **L17** for `p : MvPolynomial ι ℝ`, `∃ c M, ∀ x, |eval x p| ≤ c (1+∑ x i^2)^M` — by `MvPolynomial.induction_on`
  (or `eval_eq'`/`as_sum`): `|x i| ≤ 1 + ∑ x j^2`, so a monomial of total degree `k` is bounded by
  `|coeff| (1+∑x²)^k`; sum over the finite support. (Effort S.)

### 2.E Prop 2.4 — necessity, the weakest sufficient statement, and the textbook proof route

**Why Thm 2.15 cannot avoid a finiteness-type theorem.** With a bounded box `Y` (compact) and continuous
`Q`, for every bilevel instance the set `T := {(x,t) | ∃ z, (t,z) ∈ Θ(x)}` is closed (outer semicontinuity:
if `(xₖ,tₖ) → (x,t)` with `(tₖ,zₖ) ∈ Θ(xₖ)`, extract `zₖ → z` by compactness, then `(t,z) ∈ Θ(x)` by continuity
of `Q` and closedness of `Y`; this is the paper's Thm 2.8). The construction must achieve
`graph(h) ⊆ T ⊆ epi(h)` so that `min T_x = h(x)`. For the lsc function `h := 0 on K, 1 off K` (`K` any closed
semialgebraic set; `h` is lsc because `{h ≤ a}` is `∅`, `K` or `ℝⁿ`), the slice `T ∩ {t = ½}` is forced to be
`K × {½}` whatever sandwiched `T` is used. So every proof of Thm 2.15 along these lines must produce, for
an *arbitrary* closed semialgebraic `K`, a lower-level encoding of `K` by closed polynomial conditions in
bounded auxiliary variables. The paper's gadget `Gᵢⱼ = (P − (P²+1)z)²`, `z ∈ [0,½]`, converts a `≥`-representation
`K = ⋃ᵢ⋂ⱼ {Pᵢⱼ ≥ 0}` into such an encoding; the converse conversion is the finiteness theorem itself.
Consequently:
- The weakest statement that makes the paper's Thm 2.15 construction work is
  **(FT′)**: every closed semialgebraic `K ⊆ ℝⁿ` is `{x | ∃ z ∈ [0,1]^k, Q(x,z) = 0}` for some polynomial `Q`
  (then take `Q(x,t,z)` for `K = cl(graph h)` as the lower-level objective directly). (FT) ⇒ (FT′) is cheap
  (the gadget). I found no cheap proof of (FT′) — any such proof would be a new proof of a finiteness theorem
  for the class of sets `∃z∈box, Q=0`.
- Thm 2.20 needs (FT) itself, not (FT′): its lower level must be *convex in the lower variables*, and it
  exploits the `≥`-form through the linear gadget `−∑ₖ Pⁱⱼₖ(x) zⁱⱼₖ` on `[0,1]`; a general `∃z, Q(x,z)=0` is not
  convex in `z`.
- Using an arbitrary description of `cl(graph f)` as `⋃ {Pᵢ = 0 ∧ Qᵢⱼ > 0}` and relaxing to `≥` does NOT work:
  e.g. `K = {t = 0}` written as `{xt = 0 ∧ x > 0} ∪ {xt = 0 ∧ −x > 0} ∪ {x² + t² = 0}` relaxes to
  `{t = 0} ∪ {x = 0} ⊄ epi(h)`. Closedness + lsc give no handle on the description.
Therefore: keep Prop 2.4 as a quarantined assumption `HasFinitenessTheorem` (S4). Document (FT′) as the
true minimal need for Thm 2.15.

**Textbook proof route (verified against Schweighofer, *Real Algebraic Geometry, Positivity and Convexity*,
arXiv:2205.04211, §6.2–6.3; same as BCR 2.6–2.7), for the stretch goal:**
- **F1** = L15 (one-variable growth; Schweighofer 6.2.1). Done above.
- **F2 (compact Łojasiewicz, 6.2.2).** `A` closed bounded semialgebraic, `f g : A → ℝ` continuous with
  semialgebraic graphs, `f = 0 → g = 0` on `A`. Then `∃ N C, ∀ x ∈ A, |g x|^N ≤ C |f x|`.
  Proof: for `t > 0`, `A_t := {x ∈ A | |g x| = 1/t}` compact; `f_t := min_{A_t} |f|` exists
  (`IsCompact.exists_isMinOn`, `Topology/Order/Compact.lean:255`) and is `> 0`. `t ↦ 1/f_t` (0 if `A_t = ∅`)
  has semialgebraic graph (first-order: "`v = min`" = lower bound ∧ attained; T–S). F1 ⇒ `1/f_t ≤ t^N` for
  `t > b`. On `B := {x ∈ A | |g x| ≥ 1/b}` (compact, `f ≠ 0`), `|g|^N/|f|` is continuous hence bounded by
  `C` (`IsCompact.exists_isMaxOn`, `:273`). Combine. Effort M.
- **F3 (closed, weighted Łojasiewicz, 6.2.4).** `A` closed (unbounded) semialgebraic, same `f, g`:
  `∃ N k C, ∀ x ∈ A, |g x|^N ≤ C (1+‖x‖²)^k |f x|`. Proof in the notes: radial maxima
  `f̊(t) = max{|f x| : x ∈ A, ‖x‖ = t}` bounded polynomially by F1; divide `f, g` by `(1+‖x‖²)^{ℓ+1}` so
  they tend to 0 at infinity; **shrinking map** `φ(x) = x/√(1+‖x‖²)` (6.2.3) sends `A` into the open unit
  ball, `φ(A) ∪ S^{n−1}` is compact semialgebraic; extend `f∘ψ, g∘ψ` by `0` on the sphere, prove continuity
  there (ε-δ with compact exhaustion), apply F2, pull back. Effort L (semialgebraicity of `φ`, `ψ`:
  graph is first-order via `∃ r > 0, r² = 1 + ‖x‖² ∧ y·r = x`; continuity of the extension; transport of sets).
- **F4 (finiteness theorem, 6.3.3).** Closed case ⇔ open case by complement + distributivity
  (`compl_iUnion`, `compl_iInter`, L3). Open case: `S = ⋃ᵢ {fᵢ = 0, gᵢ₁ > 0, …, gᵢₘ > 0}` (L8); for each `i`,
  with `A := Sᶜ`, `f := fᵢ²`, `g := ∏ⱼ (|gᵢⱼ| + gᵢⱼ)` (continuous, semialgebraic, `f = 0 → g = 0` on `A`),
  F3 gives `N, k, C`; then `U := {x | C(1+‖x‖²)^k fᵢ(x)² < (2^m ∏ⱼ gᵢⱼ(x))^N ∧ ∀ j, gᵢⱼ(x) > 0}` is basic open,
  `Sᵢ ⊆ U ⊆ S` (on `A ∩ {gᵢⱼ > 0}` the Łojasiewicz inequality contradicts the strict inequality defining `U`).
  Effort M given F3.
Total stretch-goal effort: L–XL (F3 dominates). Note F1–F2 are also what a self-contained proof of
L16 needs, so the marginal cost of (FT) over Prop 2.5 is F3 + F4.

## 3. Errors, gaps and typos in the paper, with fixes

1. **Prop 2.5 is false as stated.** Take n = 2, `f(x₁,x₂) = 1/(x₁ − x₂)` for `x₁ ≠ x₂`, `f = 0` on the diagonal.
   Its graph `{(x,t) | (x₁−x₂)t = 1} ∪ {x₁ = x₂ ∧ t = 0}` is semialgebraic, but for every `C, N` the points
   `(r, r−ε)` with `r ≥ C` and `ε → 0` have `|f| = 1/ε → ∞` while `‖x‖ ≈ r√2`. The cited source
   ([51] = van den Dries–Miller, *Geometric categories and o-minimal structures*, Duke 1996, §4.12) and the
   textbook versions (Schweighofer 6.2.1 for one variable; BCR/Schweighofer 6.2.4 for continuous functions on
   closed sets) all carry a hypothesis that excludes this. **Fix:** add "f bounded on bounded sets" (true for
   `f ∈ CB`, which is the only multivariate use, Thm 2.15); for Thm 2.20 only polynomials are involved (L17).
   The proof (L16) is the one-variable sup trick.
2. **Prop 2.6 graph description assumes attainment.** With unbounded boxes the infimum of `P(x,·)` over
   `Θ(x)` need not be attained: `m = 2`, `Y = ℝ²`, `Q(x,y) = (y₁y₂ − 1)²` (so `Θ(x) = {y₁y₂ = 1}`), `P(x,y) = y₁²`:
   `inf = 0`, never attained, `φ ≡ 0`, but the paper's set `{(x,P(x,y)) | y ∈ Θ(x), ∀ y' ∈ Θ(x), P(x,y) ≤ P(x,y')}` is
   empty. **Fix:** use `{(x,t) | (∀ y ∈ Θ(x), t ≤ P(x,y)) ∧ ∀ ε > 0, ∃ y ∈ Θ(x), P(x,y) < t + ε}` (L20).
   The paper's definition of dom(φ) (with δ, ε) is correct: it says "the infimum is a real number" and
   does not require attainment (checked: `Θ(x) = ∅` is excluded by the ε-clause, `inf = −∞` by the δ-clause).
3. **Prop 2.6 is stated for boxes but used for compact convex semialgebraic Y** (Thm 2.21: `Y' = Conv(M_d(Y))`).
   **Fix:** state Prop 2.6 for any semialgebraic `Y`; boxes with `±∞` endpoints are semialgebraic (L4).
4. **Prop C.1 proof is garbled** (HTML and PDF): "H := {Pᵢ, i = 1 ∈ I}", sign vectors indexed by a symbol `I`
   that already names the index set, "for each T_I is either disjoint and included in Sᵢ for i ∈ I" (should
   read "each T_I is either disjoint from or included in each Sᵢ"), and `{<, >, =}` cells are not literally
   basic in the paper's sense: `{h < 0}` must be `{−h > 0}` and a cell may carry several equations, which must
   be merged by a sum of squares. Also the zero polynomial may occur in H (its cells `0 > 0` are empty —
   harmless). **Fix:** L5–L8.
5. **Def 2.1 typos:** "S ∈ ℝⁿ" (⊆); the definition of a semialgebraic function `f : U ⊆ ℝⁿ → ℝᵐ` tacitly needs
   `U` semialgebraic (it is, as the projection of the graph — T–S). In Lean we only use `U = ℝⁿ` and graphs.
6. **Def 2.2:** "dom(f) semialgebraic" is redundant (complement of dom⁺ ∪ dom⁻); the Lean structure keeps
   `top, bot, graph` and derives `dom`.
7. **Thm 2.3** is stated for the projection onto the first `n−1` coordinates; for `n = 0` it is vacuous. The
   "consequently first-order logic" remark is the (non-trivial but routine) induction on formulas; in the
   blueprint it is L10/L11 applied formula-by-formula, no model theory.
8. **Prop 2.4 citation** [13, Exercise 2.5.7] (Benedetti–Risler) is an exercise; the standard proofs
   (BCR Thm 2.7.2, Schweighofer 6.3.3) go through Łojasiewicz. Not a mathematical error, but the paper

9. **Thm 2.15 proof, first line:** "To prove the equalities in Theorem 2.21" should read Theorem 2.15

   `h = f/(B+‖x‖^N)` needs the *two-sided* bound `|f| ≤ B + ‖x‖^N` (the paper writes `f(x) ≤ …` after `|f(x)| ≤ …`;
   the two-sided version does follow from the two displayed bounds).
10. **Thm 2.20 observation 2** invokes Prop 2.5 for polynomials; this is elementary (L17), and the sign

11. **dom(φ)⁻** is truncated in the HTML extraction; the PDF gives `{x | ∀ δ ∈ ℝ, ∃ y ∈ Θ(x), P(x,y) < δ}`,
    which is the right set (empty `Θ(x)` is excluded automatically).
12. **§2.1, "Θ(x) … is a first-order logic expression (thus semialgebraic)"** requires `Y` semialgebraic —

13. **Section 2.4 (pessimistic):** all first-order descriptions dualise (`⨆`, `>`); the EReal lemmas L18–L20

## 5. Lean encoding decisions and pitfalls

1. **Index types.** Define everything for an arbitrary `ι` (with `[Finite ι]`/`[Fintype ι]` only where the
   proof needs it: T–S transport, closure, compactness). `Fin n` is a special case; `Fin n ⊕ Fin m` for `(x,y)`;
   `ι ⊕ Unit` for `(x,t)`. Reindexing is L4 with `F i := X (e i)`; keep one lemma `image_comp_equiv` and
   never unfold `generateSetAlgebra` downstream.
2. **`@[to_dual]`-generated names.** `le_iInf_iff`, `iInf_eq_top`, `iInf_lt_iff`, `iInf_le`, `iInf_le_of_le`,
   `iInf₂_le`, `le_iInf₂_iff`, `iInf_emptyset` exist (they are used all over Mathlib, e.g.
   `Probability/Process/Stopping.lean:323`) but have no `theorem` line of their own: they are produced from the
   `iSup` versions by `@[to_dual]` (`Mathlib/Tactic/ToDual.lean`). Do not conclude "NOT IN MATHLIB" from a
   failed grep for such names; grep for the `iSup` twin.
3. **`EReal` infimum.** `⨅ y ∈ S, (f y : EReal)` is `⨅ y, ⨅ (_ : y ∈ S), …`; empty `S` gives `⊤`
   (`iInf_emptyset`); unbounded below gives `⊥`. Never use `EReal.toReal` in statements (junk `0` at `±∞`);
   state real-valuedness as `φ x = (r : EReal)` (L20). `EReal` arithmetic is not needed in §2.1 at all.
4. **`Real.sSup` junk values** (`sSup ∅ = 0`, `sSup` of an unbounded set `= 0`): in L16 always carry
   nonemptiness (`x = 0 ∈ ball`) and `BddAbove` (from `hb`) explicitly; the first-order description of
   `s = sSup A` is only valid under these.
5. **`finSuccEquiv` isolates variable `0`**, with `Fin.cons t x`; TauCeti's T–S field also forgets coordinate
   `0` (`Fin.tail`). Put the "value"/"projected" coordinate at index `0` whenever possible (L12, L15); otherwise
   transport with `Equiv.swap`.
6. **`Fin.tail '' s` vs `{v | ∃ t, Fin.cons t v ∈ s}`**: equal by `cons_self_tail`/`tail_cons`
   (`Data/Fin/Tuple/Basic.lean:171,117`); keep both forms as simp-normal lemmas.
7. **Sup norm vs Euclidean norm.** Use `Fin n → ℝ` (sup norm, Pi topology) throughout; replace `‖x‖₂^N` by the
   polynomial `(1 + ∑ i, x i^2)^M` (brief baseline) — all growth statements in §2 are in that form, and the
   Euclidean closed ball `{∑ x i² ≤ ρ}` is a single polynomial inequality (simplest semialgebraic description).
   Only Thm 2.15's normalisation `h = f/(c(1+Σx²)^M)` consumes it; `c(1+Σx²)^M ≥ c ≥ 1` if we take `c ≥ 1`.
8. **Decidability.** Sign vectors `Fin m → SignType` are a `Fintype` with `DecidableEq`; `Finset.filter` on a
   `Prop`-valued `Φ` needs `classical` (do it: `open Classical in` or `Classical.decPred`). Nothing here is
   computable.
9. **`MvPolynomial.eval` of products/sums**: `eval_prod`, `eval_sum`, `map_pow`, `map_sub` — `eval x` is a
   `RingHom`, so `simp [map_prod]` works; for `Finset.filter` products keep the filter explicit.
10. **Boxes**: model as `a b : Fin m → EReal` with `Y := {y | ∀ i, (a i : EReal) ≤ y i ∧ (y i : EReal) ≤ b i}`
    (`EReal.coe_le_coe_iff`, `bot_le`, `le_top` make the `±∞` cases vanish definitionally) — one predicate,
    semialgebraic by case analysis per coordinate; bounded ⇔ all endpoints real.
11. **Partial graphs / thin sets**: state L12 with the hypothesis "no fibre contains an open interval"
    rather than "fibres are subsingletons", so it also serves Łojasiewicz's `t ↦ 1/f_t` (F2) and the
    min/sup-type functions, which are defined with junk values on an unbounded set of arguments.
12. **`IsClosed` on `Fin n → ℝ`** is the Pi topology = sup-norm topology; `closure`/`IsClosed` in the
    finiteness assumption refer to it (no `EuclideanSpace`).

## 6. Alternatives considered and why rejected

- **(A) as primary definition.** Rejected: closure under complement/intersection is itself the content of
  L5–L8; every proof would carry index gymnastics. (B″) gets Boolean closure for free from Mathlib's
  `IsSetAlgebra`, and (A)/Prop C.1 become theorems. Also (B″) coincides with TauCeti.
- **(C) a hand-written inductive predicate** (jbaelaw's `Semialg`): equivalent to (B″) — `generateSetAlgebra`
  *is* an inductive predicate with an induction principle; no reason to duplicate.
- **Model-theoretic definition** ("definable with parameters in the language of ordered rings", Mathlib
  `Set.Definable`): makes T–S trivial (`exists_of_finite`) but moves the hard content to quantifier
  elimination, which is needed for every *hard* inclusion (Thm 2.12, 2.15, 2.18, 2.20 all start from an
  explicit representation). Mathlib has no bridge from `Language.ring.sum Language.order` terms to
  `MvPolynomial` evaluation beyond `mvPolynomial_zeroLocus_definable`; TauCeti built that bridge (300 + 144
  lines) on top of (B″). Rejected as primary; mention as the way to state "first-order ⇒ semialgebraic" once.
- **Depending on TauCeti.** Pros: same toolchain, same definition, T–S unconditional, closure/QE/functions
  ready. Cons: enormous AI-generated dependency (24k commits), tracks Mathlib `master` (version drift), no
  finiteness theorem anyway, nothing verified by us. Recommendation: do not depend; **copy the design**
  (names, field shape) so that a one-line `instance` can be imported later if the auditor accepts it.
- **Porting jbaelaw's proof.** Self-contained (10 files), elementary method, but older Mathlib, no license,
  single AI-written commit; porting + review is itself an L–XL task. Keep as the fallback for discharging
  the class.
- **Prop 2.4 via relaxation `>` ↦ `≥` of an arbitrary description, or via CAD/Thom's lemma**: the first is
  false (§2.E example); the second needs CAD (TauCeti has CAD existence but not Thom's lemma for closures).
- **Replacing Prop 2.5 by a hypothesis in Thm 2.15**: adopted as a *layer* (Thm 2.15′), not as a replacement,
  because the growth bound is necessary for the theorem as stated and its proof (L16) is cheap given T–S.
- **Euclidean space `EuclideanSpace ℝ (Fin n)`**: rejected; nothing in §2.1 needs the Euclidean norm.

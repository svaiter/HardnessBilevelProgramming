## Baseline Lean encoding (use it unless you argue for a better one; be explicit if you deviate)
- Points of ℝ^n: `Fin n → ℝ` (sup norm; use `EuclideanSpace ℝ (Fin n)` only if the Euclidean norm matters).
  Where the paper uses ‖x‖^N with N even as a polynomial bound, prefer the polynomial `(1 + ∑ i, x i ^ 2) ^ M`.
- Polynomials: `MvPolynomial (Fin n) ℝ`, evaluated with `MvPolynomial.eval x p` (x : Fin n → ℝ).
  Upper variable x : Fin n → ℝ, lower variable y : Fin m → ℝ; a polynomial in (x,y) is
  `MvPolynomial (Fin n ⊕ Fin m) ℝ` evaluated at `Sum.elim x y`.
- A "box" Y ⊆ ℝ^m: a product of intervals, each coordinate `Set.Icc a b`, `Set.Ici a`, `Set.Iic b`, or `Set.univ`
  (model the data as `a b : Fin m → EReal` or as a predicate; propose what is cleanest).
- Bilevel data: `P Q : (Fin n → ℝ) → (Fin m → ℝ) → ℝ` (continuous / polynomial as hypotheses) and `Y : Set (Fin m → ℝ)`.
  `argminSet Q Y x := {y ∈ Y | ∀ y' ∈ Y, Q x y ≤ Q x y'}`  (= Θ(x)).
  Optimistic value function with extended reals:
  `valueFun P Q Y x : EReal := ⨅ y ∈ argminSet Q Y x, ((P x y : ℝ) : EReal)`  (empty ⇒ ⊤ = +∞; unbounded below ⇒ ⊥ = −∞).
  Pessimistic: `⨆`. Real-valued statements say `valueFun ... x = (f x : EReal)`.
- Extended-real-valued semialgebraic function (paper Def 2.2): a function `h : (Fin n → ℝ) → EReal` whose three
  sets {h = ⊤}, {h = ⊥}, {h finite} are semialgebraic and whose real-valued restriction has semialgebraic graph.
- Semialgebraic sets: two candidate definitions; agent R2 decides, others state which they assume:
  (A) paper's: finite union of basic sets {P = 0 ∧ ∀ j, Q_j > 0};
  (B) Boolean algebra generated by sets {x | 0 < eval x P} (closed under finite ∪, ∩, complement).
  (A) ⇔ (B) is elementary (sign conditions). Projection stability (Tarski–Seidenberg) is a THEOREM we
  cannot prove cheaply; treat it as an explicit hypothesis/axiom-like assumption in the blueprint where needed.
